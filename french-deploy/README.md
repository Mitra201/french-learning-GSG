# 🇫🇷 Französisch Lernen — French Exam Prep Tool

An interactive, child-friendly French learning app — fully self-contained in a single HTML file.

## ✨ Features

| Tab | Description |
|-----|-------------|
| 🏠 **Home** | Dashboard with progress stats, streak counter & category overview |
| 📖 **Wortliste** | Full vocabulary list (160+ words) with instant 🔊 pronunciation |
| 📇 **Karteikarten** | Flashcards with flip animation & text-to-speech |
| ✍️ **Schreiben** | Type-the-translation exercises with accent buttons |
| 🎤 **Sprechen** | Speech recognition practice with confidence scoring |
| 🗣️ **Dialog** | Real-life conversation gap-fill exercises |
| 📐 **Grammatik** | Grammar rules reference cards |
| 📝 **Prüfung** | Timed exam simulation (vocab, grammar & dialog mix) |
| ✅ **Gelernt** | Review all mastered vocabulary |
| 🔄 **Üben** | Smart retry for words you got wrong |
| 🔢 **Zahlen** | Numbers 0–100 with clickable grid & typing practice |

## 🚀 How to Use

**Online:** Visit the live site (link above) on any device — smartphone, tablet or PC.

**Offline:** Download `index.html` and open it in any modern browser. No server or internet needed!

## 🎯 Learning Features

- 🔊 **Text-to-Speech** — hear every word pronounced in French
- 🎤 **Speech Recognition** — practice speaking with mic input & word-level feedback
- 🏆 **Streak & Progress** — track your learning streak and mastered words
- 🎉 **Confetti Rewards** — celebrate correct answers
- 💾 **Auto-Save** — progress saved in your browser (localStorage)
- 📤 **Export/Import** — backup your progress as JSON
- ⌨️ **Accent Buttons** — é è ê ë à â ç î ï ô ù û œ æ + uppercase + apostrophe

## 📱 Works Everywhere

Responsive design — works on smartphones, tablets, laptops and desktops.
No installation, no app store, no sign-up required.
